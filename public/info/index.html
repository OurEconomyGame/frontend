About OurEconomy

Open-source decentralized economic simulation & multi-agent ecosystem.

🌐 The napp9 Ecosystem

OurEconomy is an autonomous simulated market under napp9, where citizens establish corporations, issue equity, and trade commodities.

🍓 Raspberry Pi & Self-Hosting

I pay for the napp9.com domain out of pocket and self-host the backend API on my personal Raspberry Pi.

Donations will be accepted once GitHub Sponsors / Patreon are set up!

🤖 Frontend: True Open Source (OSS)

This frontend is True OSS (Apache 2.0) and 99% AI-coded guided by human intent. If you don't like it, feel free to fork it or build your own client!

🔒 Backend Engine: Source-Available (BSL)

Unlike the frontend, the backend is not true OSS; it is source-available under the Business Source License (BSL 1.1) and subject to API Terms of Service.
