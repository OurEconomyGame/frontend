📜 Why Different Frontend & Backend Licenses?

🎨 Frontend: True Open Source (Apache 2.0)

Permissive licensing maximizes community innovation, allowing anyone to build custom dashboards, mobile apps, bots, or fork the client freely without restrictions. (99% AI-coded guided by human intent).

🔒 Backend: Source-Available (BSL 1.1)

The backend engine is 100% public on GitHub for transparency and auditing, but BSL protects core simulation IP from commercial turnkey clones and maintains unified market liquidity.

🎁 Contributor In-Game Rewards

Open-source contributors, bug reporters, and PR authors will be rewarded with in-game rewards (starter cash and founder perks)!
