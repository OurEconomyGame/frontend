Privacy Policy

Last updated: August 2026

1. Information We Collect & Local Storage

We collect basic account credentials (username and hashed secrets) to authenticate sessions. We do not sell or monetize personal data.

Local Storage: We use browser localStorage to store session tokens (oe_token), handle (oe_username), ID (oe_user_id), and theme (oe_theme). No tracking cookies are used.

2. Server Logging & Simulation Telemetry

Infrastructure Logs: Web requests are processed via Google Firebase Hosting and our Bun server, which automatically log technical metadata (IP addresses, request headers, timestamps) for routing and abuse prevention.

Public Ledger: In-game actions (founding companies, trades, orderbook depth, dividends, shifts) are recorded openly on the public simulation ledger.

3. Account Deletion & Separate Backend Policy

Data Erasure: Upon request, we delete all user record data and credentials under direct database control (external CDN logs cannot be altered).

Separate Backend Policy: This policy governs the frontend web client. The backend server and API infrastructure operate under a separate Backend Privacy Policy on GitHub.

4. Age Policy (13+) & Revisions

OurEconomy is intended solely for users aged 13 and older (COPPA / GDPR alignment).

External links (such as GitHub) follow their own policies. Revisions to this policy are posted directly to this page. For inquiries, visit the OurEconomyGame Organization.
